# Academic Homepage for GitHub Pages

This is a minimal academic homepage designed for use as a personal link on OpenReview,
conference profiles, CVs, and research applications.

## 1. Replace the placeholders

Edit `index.html` and replace:

- `Your Name`
- `your_email@example.com`
- `YOUR_GITHUB_USERNAME`

You can also edit the research interests and project descriptions.

## 2. Create a GitHub repository

Recommended repository name:

`YOUR_GITHUB_USERNAME.github.io`

For example, if your GitHub username is `alice123`, create:

`alice123.github.io`

## 3. Upload these files

Upload:

- `index.html`
- `styles.css`

to the root directory of the repository.

## 4. Enable GitHub Pages

Go to:

Settings → Pages

Set:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

After deployment, your homepage will be available at:

`https://YOUR_GITHUB_USERNAME.github.io`

## 5. Use it on OpenReview

Paste that URL into the `Personal Links` field.

## Suggested future additions

Once you have more research output, add:

- Publications / Preprints
